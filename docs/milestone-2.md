# Milestone 2: что сделано

Критерии оценки: AI AGENT, READY DESIGN, PAY system.

## AI AGENT

- **Провайдер LLM.** Claude API или бесплатный Groq (`openai/gpt-oss-120b`), выбирается ключом в `backend/.env`.
- **Агент заявок** (`backend/app/agents/intake.py`). Текст клиента отправляется в языковую модель со структурированным выводом (JSON-схема): города, вес в тоннах, дата, тип машины из списка, адрес, груз, уверенность и список недостающих полей. Модели запрещено угадывать: если поля нет, она ставит null.
- **Порог уверенности.** Итоговая уверенность — меньшее из двух: оценки модели и полноты полей. При уверенности ≥ 80% заявка создаётся автоматически и получает трёх перевозчиков с ценой по расстоянию. Ниже 80% — уходит в очередь менеджера с причиной.
- **Агент поддержки** (`backend/app/agents/support.py`). Работает в цикле вызова инструментов: модель сама решает, вызвать `get_request`, `list_my_requests`, `search_faq` или `escalate_to_manager`. Инструменты видят только заявки своей компании. В чате видно, какие инструменты вызывались.
- **Человек в контуре.** Менеджер заполняет недостающие поля, подтверждает или возвращает заявку клиенту. Все решения агентов и людей пишутся в журнал.
- **Отказоустойчивость.** Если ключа нет или API недоступен, срабатывает запасной разбор на правилах. Интерфейс это показывает («Агент: правила»), чтобы правила не выдавались за ИИ.

## READY DESIGN

- Макет в Figma: 5 экранов, кликабельный прототип.
- Реализация макета: `frontend/index.html` — главная, вход по ролям, кабинет клиента, очередь менеджера, тарифы, оплата, журнал. Светлая и тёмная тема, адаптивная вёрстка.

## PAY system

- Три тарифа с лимитом заявок: Старт $0 / 50, Business $29 / 500, Pro $99 / 3000.
- Оплата через **Stripe Checkout в тестовом режиме** (подписка, `backend/app/billing.py`): сервер создаёт сессию, пользователь платит тестовой картой 4242 4242 4242 4242 на странице Stripe, после возврата сервер проверяет сессию и меняет тариф. Поддержан вебхук `checkout.session.completed`.
- Лимит работает: когда заявки по тарифу кончаются, агент перестаёт принимать новые, пока тариф не сменят.
- Без ключа Stripe работает демо-оплата, которая принимает только тестовую карту.

## Как показать на защите

1. Войти клиентом, отправить пример «Алматы → Астана»: заявка создана автоматически, есть перевозчики.
2. Отправить пример «Неполная»: заявка ушла менеджеру.
3. В чате спросить «где заявка 1042?» и «сколько стоит страховка?»: видно вызванные инструменты.
4. Войти менеджером: дозаполнить заявку и подтвердить.
5. Войти владельцем: оплатить тариф Pro в Stripe тестовой картой.
6. Войти администратором: журнал показывает все шаги.
