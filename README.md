# LogiAgent

ИИ-агенты для обработки заявок, накладных и обращений клиентов в логистике.

## Описание

Веб-система для небольших экспедиторских компаний. Три агента на базе LLM берут на себя рутину сотрудников, а сложные случаи передают человеку:

1. **Агент заявок** достаёт маршрут, вес и дату из текста клиента, создаёт заявку и подбирает перевозчика с ценой.
2. **Агент документов** читает накладную и сверяет её с заявкой, поднимает флаг при расхождениях.
3. **Агент поддержки** отвечает клиентам о статусе груза по базе знаний.

Проект является продолжением дипломной темы «Разработка информационной системы автоматизации бизнес-процессов предприятия с использованием ИИ-агентов».

## Стек

- Frontend: React, TypeScript, Vite
- Backend: Python, FastAPI
- БД: PostgreSQL + pgvector
- Оплата: Stripe (test mode)
- LLM: Claude API
- ML: scikit-learn, pandas
- DevOps: Docker, GitHub Actions

## Структура

```
frontend/  веб-кабинет
backend/   API, агенты, оплата
ml/        модели и эксперименты
docs/      документация, схемы, диаграмма Ганта
```
